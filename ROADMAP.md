# Roadmap

This roadmap describes the direction of `pcampus-openapi-kit` after v1.0.0.

## v1.0.0 — Foundation (shipped)

- CLI: lint, validate, init
- Spectral rules for Pcampus conventions
- Shared error and pagination schemas
- Billing invoice module (reference domain spec)
- FastAPI reference implementation
- CI, contributor docs, and issue templates

## v1.1.0 — Expand Reusable Modules

- [ ] Auth module with token and principal endpoints
- [ ] CRM customer module starter spec
- [ ] Notifications subscription module starter spec
- [ ] Published npm package for shared schemas

## v1.2.0 — Framework Coverage

- [ ] Laravel example mirroring FastAPI billing implementation
- [ ] Node.js example with shared error middleware
- [ ] AI agent workflow examples under `examples/ai-agent/`

## v1.3.0 — Automation

- [ ] GitHub Action published to GitHub Marketplace
- [ ] SDK generation scripts for TypeScript and Python
- [ ] Contract test generator under `generated/tests/`

## How To Influence The Roadmap

1. Open a [Feature Request issue](https://github.com/pcampus-studio/pcampus-openapi-kit/issues/new/choose)
2. Comment on an existing roadmap item you want to help with
3. Submit a pull request linked to an issue

See [GOOD_FIRST_ISSUES.md](GOOD_FIRST_ISSUES.md) for beginner-friendly contribution ideas.
