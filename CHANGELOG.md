# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-28

### Added

- `@pcampus/openapi-kit` CLI with `lint`, `validate`, and `init` commands
- Spectral ruleset enforcing Pcampus OpenAPI conventions
- Complete billing invoice module at `specs/billing/openapi.yaml`
- Runnable FastAPI reference implementation in `examples/fastapi/`
- Mock server script using Prism
- Quickstart, roadmap, and contributor documentation
- GitHub Actions CI and reusable validate action
- Issue and pull request templates for community contributions
